# AI Web Scraper

This project is an AI-powered web scraper built using Python, Selenium, LangChain, and Ollama.

## Features

* Scrapes website data
* Uses AI to extract structured information
* Returns clean table/JSON format
* Supports local LLMs using Ollama

## Technologies Used

* Python
* Selenium
* LangChain
* Ollama
* Gemma 2B

## How to Run

```bash
pip install -r requirements.txt
python main.py
```
